# One Star for Monday

A make.fun entry for [One Star for Monday](https://make.fun/competitions/u-clever-harbor-75-one-star-for-monday-9ead4a61): a program that writes a one-star review of Monday, as if Monday were a restaurant, to `/output/entry.txt` — 25 words or fewer, one line, plain text.

Run it with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
